# ⚡ Fastload

Lightweight Windows app to download **video, music and thumbnails** from YouTube and 1800+ other sites.
Лёгкая программа для Windows: скачивает **видео, музыку и обложки** с YouTube и ещё 1800+ сайтов.

**[⬇ Download the latest version / Скачать последнюю версию](https://github.com/millionvest/fastload-releases/releases/latest)** — `Fastload-Setup-x.y.z.exe`

- 🎬 Video up to 4K, playlists and whole channels · Видео до 4K, плейлисты и каналы целиком
- ✂️ Download only a fragment of a video · Скачивание только фрагмента видео
- 🎵 MP3 / M4A with cover and tags · MP3 / M4A с обложкой и тегами
- 🖼 Thumbnails in max quality · Обложки в максимальном качестве
- 🌍 English, Русский, Español, Deutsch, Português
- 🔄 Updates itself · Обновляется сама

This repository contains only installers. · Здесь только установщики.
